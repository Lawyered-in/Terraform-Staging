1. REPOSITORY OVERVIEW
================================================================================

This repository is the COMPLETE INFRASTRUCTURE-AS-CODE (IaC) for the
Lawyered-in platform running on AWS. It manages everything from networking
to application deployment using Terraform + GitOps (Argo CD).

  Project Name  : Lawyered-in Platform Infrastructure
  Cloud         : AWS (ap-south-1 / Mumbai)
  IaC Tool      : Terraform >= 1.5.0
  GitOps Tool   : Argo CD
  CI/CD         : AWS CodePipeline + CodeBuild
  Kubernetes    : EKS (Elastic Kubernetes Service)
  Database      : Aurora MySQL 8.0 (Serverless v2)
  Registry      : Amazon ECR (7 repositories)
  State Backend : S3 (tf-statefile-npbucket)

What this repo does in one sentence:
  "Push code to GitHub staging branch → Docker image built → pushed to ECR →
   Kubernetes manifest updated → Argo CD deploys to EKS automatically."
