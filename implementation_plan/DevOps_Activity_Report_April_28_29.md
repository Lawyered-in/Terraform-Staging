## ಭಾಗ 1: ಏಪ್ರಿಲ್ 28, 2026 (ಸಮಸ್ಯೆ ಪರಿಹಾರ ಮತ್ತು ಹೊಸ ಸರ್ವಿಸ್ ಸೆಟಪ್)

### 1.1 ArgoCD PVC ಇಮ್ಮ್ಯುಟಬಿಲಿಟಿ (Immutability) ಸಮಸ್ಯೆ ಮತ್ತು ಪರಿಹಾರ
**ಸಮಸ್ಯೆ (Problem):** "stg-admin-lawyered" ಅಪ್ಲಿಕೇಶನ್ ಸಿಂಕ್ ಆಗಲು ವಿಫಲವಾಗುತ್ತಿತ್ತು. 
**ತಾಂತ್ರಿಕ ಕಾರಣ (Root Cause):** 
Kubernetes ನಲ್ಲಿ ಒಂದು ಬಾರಿ PVC (PersistentVolumeClaim) ಕ್ರಿಯೇಟ್ ಆಗಿ ಅದು ಒಂದು ವಾಲ್ಯೂಮ್‌ಗೆ (PV) ಲಿಂಕ್ ಆದ ಮೇಲೆ, ಅದರ `volumeName` ಫೀಲ್ಡ್ ಅನ್ನು ಬದಲಾಯಿಸಲು ಸಾಧ್ಯವಿಲ್ಲ. ನಮ್ಮ GitHub ಮ್ಯಾನಿಫೆಸ್ಟ್‌ನಲ್ಲಿ ಅದು ಖಾಲಿ ಇತ್ತು (`""`), ಆದರೆ ಕ್ಲಸ್ಟರ್‌ನಲ್ಲಿ ಅದಕ್ಕೆ ಒಂದು ಹೆಸರು ಸಿಕ್ಕಿತ್ತು. ArgoCD ಅದನ್ನು ಓವರ್‌ರೈಟ್ ಮಾಡಲು ಪ್ರಯತ್ನಿಸಿದಾಗ ಈ ಎರರ್ ಬರುತ್ತಿತ್ತು.

**ಪರಿಹಾರ (Solution):**
ನಾವು ArgoCD ಅಪ್ಲಿಕೇಶನ್ ಫೈಲ್‌ನಲ್ಲಿ `ignoreDifferences` ಅನ್ನು ಸೇರಿಸಿದ್ದೇವೆ ಮತ್ತು `ServerSideApply` ಅನ್ನು ಸಕ್ರಿಯಗೊಳಿಸಿದ್ದೇವೆ.

**ಕೋಡ್ ಉದಾಹರಣೆ:**
```yaml
spec:
  ignoreDifferences:
    - group: ""
      kind: PersistentVolumeClaim
      jsonPointers:
        - /spec/volumeName
  syncPolicy:
    syncOptions:
      - ServerSideApply=true
```

## ಭಾಗ 3: Git ಕಾರ್ಯಾಚರಣೆಗಳು ಮತ್ತು ದೊಡ್ಡ ಫೈಲ್‌ಗಳ ನಿರ್ವಹಣೆ

### 3.1 "A to Z" ಫೈಲ್ ಪುಶ್ (Push) ಸವಾಲು
ನೀವು "ಒಂದೂ ಫೈಲ್ ಬಿಡದೆ ಎಲ್ಲವನ್ನೂ GitHub ಗೆ ಅಪ್‌ಲೋಡ್ ಮಾಡಬೇಕು" ಎಂದು ಸೂಚಿಸಿದಾಗ ನಮಗೆ ದೊಡ್ಡ ಸವಾಲು ಎದುರಾಯಿತು. 

**ಸವಾಲು:** GitHub ಒಂದು ಫೈಲ್‌ಗೆ ಗರಿಷ್ಠ 100MB ಮಿತಿಯನ್ನು ಹೊಂದಿದೆ. ಆದರೆ ನಮ್ಮ `.terraform` ಫೋಲ್ಡರ್‌ನಲ್ಲಿ 800MB ಗಿಂತ ದೊಡ್ಡದಾದ AWS ಪ್ರೊವೈಡರ್ ಫೈಲ್‌ಗಳಿದ್ದವು.

### 3.2 Git LFS (Large File Storage) ಪರಿಹಾರ
ಈ ದೊಡ್ಡ ಫೈಲ್‌ಗಳನ್ನು ಅಪ್‌ಲೋಡ್ ಮಾಡಲು ನಾವು Git LFS ಅನ್ನು ಬಳಸಿದ್ದೇವೆ. ಇದು ದೊಡ್ಡ ಫೈಲ್‌ಗಳನ್ನು ಬೇರೆಯೇ ರೀತಿಯಲ್ಲಿ ಹ್ಯಾಂಡಲ್ ಮಾಡುತ್ತದೆ.

**ಬಳಸಿದ ಕಮಾಂಡ್‌ಗಳು:**
1. `git lfs install`: LFS ಸೌಲಭ್ಯವನ್ನು ಶುರು ಮಾಡಲು.
2. `git lfs track "*.exe"`: ದೊಡ್ಡ ಬೈನರಿ ಫೈಲ್‌ಗಳನ್ನು ಟ್ರ್ಯಾಕ್ ಮಾಡಲು.
3. `git add .`: ಎಲ್ಲಾ ಫೈಲ್‌ಗಳನ್ನು ಸೇರಿಸಲು.
4. `git commit`: ಬದಲಾವಣೆಗಳನ್ನು ಖಚಿತಪಡಿಸಲು.
5. `git push origin main`: ಇಡೀ ಕೋಡ್ ಅನ್ನು GitHub ಗೆ ಕಳುಹಿಸಲು.

## ಭಾಗ 4: DevOps ಇಂಜಿನಿಯರ್‌ಗೆ ಪ್ರಮುಖ ಟಿಪ್ಸ್

1. **.terraform ಫೋಲ್ಡರ್:** ಸಾಮಾನ್ಯವಾಗಿ ಇದನ್ನು GitHub ಗೆ ಹಾಕುವುದಿಲ್ಲ ಏಕೆಂದರೆ ಇದು ಕೇವಲ ಒಂದು ಕ್ಯಾಶ್ (Cache). ಆದರೆ ನೀವು "A to Z" ಬೇಕು ಎಂದಿದ್ದರಿಂದ ನಾವು LFS ಮೂಲಕ ಇದನ್ನು ನಿರ್ವಹಿಸಿದ್ದೇವೆ.
2. **Security:** ಡೇಟಾಬೇಸ್ ಪಾಸ್‌ವರ್ಡ್‌ಗಳನ್ನು ನೇರವಾಗಿ ಕೋಡ್‌ನಲ್ಲಿ ಹಾಕದೆ AWS Secrets Manager ಮೂಲಕ ನಿರ್ವಹಿಸುವುದು ಉತ್ತಮ.
3. **ArgoCD Sync:** ಯಾವಾಗಲೂ `ServerSideApply` ಬಳಸುವುದರಿಂದ ಇಮ್ಮ್ಯುಟಬಿಲಿಟಿ ಎರರ್‌ಗಳನ್ನು ತಪ್ಪಿಸಬಹುದು.
