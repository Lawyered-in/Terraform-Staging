REQUIREMENT
-----------
  Push every single file in the repository (including .terraform cache and binaries) to GitHub.

TECHNICAL CHALLENGE
-------------------
  GitHub rejects files larger than 100MB. The .terraform folder contains AWS provider binaries exceeding 800MB.

SOLUTION
--------
  Implemented Git LFS (Large File Storage) to track and upload these heavy files.

COMMANDS USED
-------------
  - git lfs install
  - git lfs track "*.exe"
  - git add .
  - git commit -m "Include all files A to Z including large binaries using Git LFS"
  - git push origin main

STATUS
------
  The push is currently uploading ~1.8 GB of data to the remote repository.
